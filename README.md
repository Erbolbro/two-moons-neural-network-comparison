# Neural Network Architecture Comparison

This project investigates how the number of hidden neurons
affects classification accuracy, training time, and
generalization in artificial neural networks.

## Experiment

- Dataset: Two Moons
- Hidden neurons: 4, 16, 64
- Repetitions: 10 per architecture
- Algorithm: MLPClassifier (Scikit-learn)

## Technologies

Python, Scikit-learn, NumPy, pandas, Matplotlib

## Run the experiment

pip install -r requirements.txt
python neural_network.py

## Results

The experiment generates a CSV file containing the results
of 30 training runs and two comparison graphs.

## Academic Context

Research project for the Architecture of Computers course
at Vistula University.
